# Marketplace scraper for facebook Privacy Policy

Static privacy-policy site for the Marketplace scraper for facebook Chrome extension.

## Publish with GitHub Pages

1. Create a GitHub repository and copy this folder’s contents to its repository root.
2. Push the repository to GitHub.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the publishing branch and the root folder, then save.
5. Use the generated HTTPS URL as the Chrome Web Store privacy-policy URL.

The site has no build step, scripts, analytics, cookies, or external assets. Update the date and policy whenever the extension’s data practices change.
